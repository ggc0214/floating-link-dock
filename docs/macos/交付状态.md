# Mac M 系列版 · 实施状态

2026-10-08。已在本机 macOS 26.5.1 / Apple Silicon 构建应用和 ZIP，仍处于实机验收阶段。

**当前包要求 macOS 26 或以上。** Homebrew Python 3.13.16 / Tk 9.1.0 的编译最低版本为26；构建现已根据实际二进制推导系统声明。原方案的 macOS 13+ 是目标，13–15 兼容包与实测尚未完成。

独立只读代码审查指出两项问题，已用失败测试重现并修复：错误日志测试在 Mac 上写真实用户目录；损坏/不可读的启动配置令应用无法打开。现在测试使用临时目录，启动配置异常是可修复的非致命警告。无待处理的轻微审查项。

当前 Windows Python/Tk 在原运行库路径有偶发读取失败（文件实际存在，基线也曾发生）。最后验证仅为测试进程设置工作区内运行库副本，未更改系统安装或产品配置。保留此限制，不将原环境稳定性宣称已修复。

本目录是无 `.git` 历史的最新源码交接，历史分支名仅描述此前Windows环境。本次保留现有文件，没有初始化仓库、推送或发布。

本次修复最低系统声明和Tk恢复Dock模式的问题，补充原生回归测试；独立审查发现的Windows打包测试依赖缺失已补充。完整命令与失败过程见[实施记录](./实施记录.md)。

需用户继续验收：手动点击收起/展开、添加和方块右键、顶部笑脸菜单显示/重置/退出20次、边缘吸附与半隐藏、多屏、真实登录启动，以及第二台兼容M系列Mac安装。验收前不作为正式发布包。

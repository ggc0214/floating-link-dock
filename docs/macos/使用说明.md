# 常用网址盒 · Mac 使用说明

当前已生成本机验收包，位于 `dist/macos-arm64/`，尚未完成全部人工验收和第二台Mac验收。

## 安装和打开

当前包适用于 Apple Silicon、macOS 26或以上，本机验证系统为26.5.1。原方案目标是macOS 13+，但当前构建的Python/Tk依赖最低要求26；13–15需要兼容运行库重新构建和验证。Intel Mac 不使用此包。

1. 解压 `FloatingLinkDock-macos-arm64.zip`。
2. 把 `FloatingLinkDock.app` 拖到“应用程序”。
3. 双击打开。网址面板应自动展开，顶部菜单栏出现笑脸，不占 Dock。

首版构建仅作本地临时签名，没有 Apple 开发者签名或公证。只有确认来源可信时，才按系统提供的“隐私与安全性 → 仍要打开”提示处理；若没有该选项、提示损坏或被管理策略限制，请保留提示并联系提供者。不要关闭整个系统的安全检查。

## 日常使用

- 添加：点“＋ 添加”，填写名称和网址，点保存。
- 打开：单击网站方块，使用你的默认浏览器。
- 换浏览器：右键方块，选择 Safari、Chrome、Edge 或 Firefox。只列出常规位置已安装的浏览器，只影响这一次打开。
- 触控板右键：双指点按；也可按住 Control 再单击。
- 整理：按住网站方块拖动，松开后自动保存位置；长名称会换行，方块不显示网址。
- 编辑或删除：右键方块选择对应菜单。
- 收起：点左上角笑脸或右上角减号；再点小笑脸展开。
- 移动窗口：按住标题区拖动，靠近屏幕边缘会吸附。
- 半隐藏、置顶：右键标题区或小笑脸，在菜单里勾选。

## 找不到窗口和退出

点顶部菜单栏的笑脸，选择“显示网址”。位置不合适时选“重置位置”。

要完全退出，选择菜单栏笑脸里的“退出”，不是只把窗口收起。再次打开应用应恢复为展开状态。

## 开机启动

先把应用放到固定的“应用程序”目录，再右键标题区或小笑脸，勾选“开机启动”。取消勾选即可关闭，下次登录生效。

如果移动或改名了应用，重新打开后按提示重新启用。此功能只管理本应用的个人启动条目，不改其他应用。直接运行源码不能启用。

## 备份、更新和分享

在 Finder 选择“前往 → 前往文件夹”，输入：

`~/Library/Application Support/FloatingLinkDock`

退出应用后，复制整个文件夹即可备份。`links.json` 保存网址和方块位置，`settings.json` 保存设置，`backups` 保存损坏数据备份，`errors.log` 记录错误。分享日志前留意其中可能包含的网址或个人路径。

更新时先退出，再用新版 `.app` 替换原应用；用户数据保存在上面的独立文件夹中。位置变化后重新设置开机启动。

分享给别人只发通过实测的 ZIP，不附带你的数据文件夹。对方要用 M 系列 Mac。当前尚未完成另一台 Mac 分享验收。

## 开发者：在 Mac 构建

需要处于已登录桌面的 M 系列 Mac、原生 arm64 Python 3.11 或以上及 Tk。本机默认pyenv Python没有Tk，实际采用 `/opt/homebrew/bin/python3.13`，Python 3.13.16 / Tcl-Tk 9.1.0。终端进入源码目录，创建独立环境：

```bash
/opt/homebrew/bin/python3.13 -m venv .venv-macos
source .venv-macos/bin/activate
python -m pip install -r requirements-dev.txt
bash scripts/build_macos.sh
```

脚本先跑测试，再生成图标、arm64 `.app` 和 ZIP，检查主程序架构及本地签名完整性。最低系统声明从实际收集的二进制计算；更换Python/Tk后需重新检查。输出位于 `dist/macos-arm64/`，不覆盖 Windows 程序；不会上传或发布。

打包成功后仍须检查：启动展开、菜单栏20次操作、无 Dock 图标、Retina和多屏拖动/半隐藏、浏览器打开、重复启动、退出重启、个人开机启动，以及另一台 M 系列 Mac 安装。未经这些检查，不称为正式可用版本。

实现依据：[pystray 事件循环说明](https://pystray.readthedocs.io/en/latest/faq.html)、[Apple NSScreen](https://developer.apple.com/documentation/appkit/nsscreen)、[PyInstaller Mac 构建说明](https://pyinstaller.org/en/stable/feature-notes.html)。

# Mac M 系列版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为现有网址盒增加 Apple Silicon Mac 支持，交付不显示 Dock 图标的菜单栏悬浮应用、arm64 分享包与说明。

**Architecture:** 复用 Tk 界面和 JSON 业务层，系统调用通过平台入口切换 Windows/Mac 实现。新增 Mac 浏览器、屏幕、启动管理和单实例适配。Mac 原生菜单栏及 Tk 主线程集成须在实机验证后才接受。

**Tech Stack:** Python、CustomTkinter、Pillow、pystray/PyObjC、PyInstaller、pytest。保留现有依赖版本；Mac 专属依赖使用环境标记并在 Mac 上验证兼容。

## Global Constraints

- Apple Silicon arm64；首版目标 macOS 13+，实际最低版本以构建和验收为准。
- 保留浅绿色背景、网站方块、自由拖动、吸附、可选半隐藏和置顶。
- 顶部菜单栏入口，不显示 Dock 图标；每次正常启动展开。
- 单击默认浏览器；右键选择 Safari、Chrome、Edge、Firefox，只影响本次打开。
- Windows 版行为、已有数据格式和当前用户文件保持不变。
- 开机启动默认关闭；只修改用户主动启用的本应用条目。
- 不携带私人数据，不全局关闭安全检查，不擅自购买签名服务或创建云构建。
- Windows 测试不能替代 Mac 实机验收；当前会话执行环境仍是 Windows。
- 当前上下文提示不是 Git 仓库：不初始化仓库，不强行提交；如后续确认有可用仓库，仅提交本任务文件，保留原有修改。

## Review Focus

1. Cocoa/Tk 两个事件循环：菜单操作应稳定响应，不挂住窗口（任务4）。
2. Retina、多屏负坐标或上下排列：吸附与展开不可把窗口留在屏幕外（任务3）。
3. 应用移动、浏览器移除、含空格路径：失败提示清楚，不破坏默认浏览器或启动配置（任务2、5）。
4. 重复启动或崩溃：只能出现一个实例，后续打开能恢复窗口（任务5）。
5. 干净 Mac、未经公证 ZIP：明确架构与安全状态，不把开发机可启动当作分发已验证（任务6）。
